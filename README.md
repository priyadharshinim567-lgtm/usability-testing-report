# StudyFlow — Usability Testing Report

> **CODTECH UI/UX Internship Project**

A usability testing case study evaluating the **StudyFlow** student productivity experience, identifying usability issues, analyzing user behavior, and translating findings into actionable UX recommendations.

---

## 📌 Overview

**StudyFlow** is a conceptual study planning and productivity application designed for college students to manage:

* Assignments
* Exams
* Deadlines
* Study sessions
* Task priorities
* Weekly workload
* Completion progress

This project focuses on evaluating the usability of the proposed StudyFlow experience through task-based usability testing.

The study follows the UX process:

**Test → Observe → Analyze → Prioritize → Recommend → Iterate**

---

## 🎯 Project Objective

The objective of this usability testing project is to understand how easily students can complete common academic planning tasks and identify areas of friction within the StudyFlow experience.

The testing focuses on whether users can:

* Understand the dashboard
* Create an academic task
* Set a deadline
* Prioritize a task
* Find upcoming deadlines
* Schedule a study session
* Mark tasks as completed
* Understand their progress

## 🧪 Usability Testing Methodology

### Testing Type

Moderated, task-based usability testing.

### Target Users

College students approximately between the ages of 18–24 who manage multiple academic responsibilities.

### Sample Participants

6 anonymous sample participants were used for the case-study demonstration.

### Session Duration

Approximately 15–20 minutes per participant.

### Data Collected

* Task completion
* Task errors
* Completion time
* User hesitation
* Observed confusion
* Assistance required
* Satisfaction ratings
* Qualitative feedback
